# Jobber Keyboard Shortcuts — Firefox Add-on

This is the Firefox extension version of the
[Jobber Keyboard Shortcuts](../README.md) userscript. It adds the same keyboard
shortcuts to [secure.getjobber.com](https://secure.getjobber.com) without a
userscript manager. It requires Firefox 128 or later because it runs the
shortcut logic in Jobber's main JavaScript world.

> The shortcut logic lives in the canonical
> [`../jobber-keyboard-shortcuts.js`](../jobber-keyboard-shortcuts.js). The
> `content.js` file here is auto-generated by
> [`../sync-extension.sh`](../sync-extension.sh); do not edit it by hand.

## Install from Firefox Add-ons

[**Install Jobber Keyboard Shortcuts from Firefox Add-ons**](https://addons.mozilla.org/addon/jobber-keyboard-shortcuts/)

Click **Add to Firefox**, then open [Jobber](https://secure.getjobber.com).
The add-on updates automatically when new versions are released.

## Install locally (for testing)

1. Download or clone this repository.
2. Open `about:debugging#/runtime/this-firefox` in Firefox.
3. Select **Load Temporary Add-on…** and choose
   `firefox-extension/manifest.json`.
4. Open [Jobber](https://secure.getjobber.com). The shortcuts are live; click
   the toolbar icon for the shortcut reference.

Temporary add-ons are removed when Firefox restarts. To try a new version,
reload the add-on from `about:debugging` after pulling the changes.

## Build the Firefox package

Run this from the repository root:

```bash
./build-firefox-xpi.sh
```

It creates `jobber-keyboard-shortcuts-firefox.xpi`, containing only the runtime
files needed by Firefox. This is useful for testing or preparing a new Mozilla
Add-ons submission; most users should install the
[published Firefox Add-ons version](https://addons.mozilla.org/addon/jobber-keyboard-shortcuts/).

## Technical notes

The content script runs in Jobber's main JavaScript world, matching the
userscript and Chrome extension behavior. It requires no permissions beyond
access to `https://secure.getjobber.com/*`, and the add-on does not collect or
transmit data.
